## 🚀 How to Run Locally

You can open the portfolio directly in any modern browser or serve it using Python or Node.js:

### Option 1: Direct File Opening
Double-click `index.html` or open `file:///c:/Users/Admin/Downloads/AARTHI-PORTFOLIO/index.html` in Chrome, Edge, or Safari.

### Option 2: Using Python HTTP Server
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.

### Option 3: Using Node.js (npx serve)
```bash
npx serve .
```
